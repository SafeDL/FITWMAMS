# 自回归交通世界模型目标

训练gpu环境在系统的:
conda activate tread

## 1. 当前基础与目标

本轮以冻结的 BARS-M1 为唯一实现起点，形成受控的 BARS-M2；不以 `catk_topk` 为实现基础，
不导入其模型、候选分支、损失或 checkpoint。

BARS-M1 已保留的基础能力：

- 每 0.2 秒读取当前自车状态并重新编码交通关系；
- 使用生成的背景车历史继续自回归滚动；
- 场景级离散交互状态及持续时间；
- 关系编码器、车辆动力学、首秒行为锚点和可重放随机数；
- 第一秒后不再读取行为锚点。

BARS-M1 当前的主要缺口：

- ROLL 每次只预测一个 0.2 秒控制，而不是未来一秒计划；
- 没有相邻计划的 0.8 秒重叠约束；
- 半马尔可夫状态在训练中尚未完全按完整交互阶段建模；
- 多车具有联合编码，但未来计划仍缺少计划层面的联合约束。

目标模型定义为：

> **持续交互意图驱动的重叠视野联合自回归交通世界模型。**

正式运行流程：

```text
过去一秒历史
→ 保持或切换持续交互意图
→ 预测未来一秒多车计划
→ 只执行前 0.2 秒
→ 写回生成状态并重新规划
```

---

## 2. 固定边界

- 冻结 76 维 Normalizing Flow、checkpoint、schema 和标准化规则。
- START 可读取首秒行为锚点；第一秒后任何模块不得读取该锚点。
- ROLL 只读取已发生的自车状态、已生成背景车历史、道路图和内部交互状态。
- 禁止输入 ego future、未来背景车、ADS 身份、ADS 网络特征、风险标签、EVT 标签或 `risk_trace`。
- 保持 25 Hz、0.2 秒响应间隔、六背景车槽位和现有动力学。
- 不增加 CAT-K 候选、扩散模型、逐车离散隐变量、车辆出生消失或槽位重分配。

## 3. 核心修改一：一秒控制计划解码器

将 `IntentResponseDecoder` 的输出由：

```text
[B, agents, 2]
```

改为：

```text
[B, 25, background_agents, 2]
```

每次只执行前五帧：

```text
applied_controls = control_plan[:, 0:5]
```

计划分解为：

```text
control_plan = intent_plan + local_residual_plan
```

要求：

- `intent_plan` 由场景级交互意图、意图已持续时间和全局交通表示生成；
- `local_residual_plan` 由每辆车的关系表示生成；
- 局部修正有独立幅值上限和平滑约束；
- 时间展开后增加一次轻量跨车辆交互，使所有背景车计划相互兼容；
- 真实动作监督只作用于最终 `applied_control_plan`，不能直接用完整真实动作监督局部修正。

START 与 ROLL 共用同一个计划解码器：

```text
START：B0_nominal_plan + intent_plan + local_residual_plan
ROLL：intent_plan + local_residual_plan
```

模型和评测必须分别返回：

```text
b0_nominal_plan
intent_plan
local_residual_plan
applied_control_plan
```

## 4. 核心修改二：0.2 秒执行的一秒重叠视野

每 0.2 秒预测未来一秒，但只执行前 0.2 秒。

相邻两次计划的重叠区间为：

```text
old_plan[:, 5:25]
new_plan[:, 0:20]
```

环境必须保存：

```text
previous_control_plan
previous_plan_valid
previous_relation_summary
previous_intent_state
plan_response_index
```

增加重叠一致性损失：

```text
L_overlap = overlap_weight * distance(
    old_plan[:, 5:25],
    new_plan[:, 0:20]
)
```

`overlap_weight` 只根据两个更新时刻之间已经观察到的关系变化计算：

- 关系变化小时，约束新旧计划连续；
- 关系明显变化时，允许重新规划；
- 意图发生切换时降低重叠权重，但仍保留动作连续性约束。

`snapshot()` 和 `restore()` 必须保存并恢复上一计划及对齐位置。

---

## 5. 核心修改三：段级持续交互意图

保留现有半马尔可夫离散状态作为唯一场景级持续交互意图。

正式语义：

```text
阶段开始：采样一次意图和持续时间
阶段内部：严格保持当前意图
持续时间结束：根据当前场景和上一意图选择下一意图
```

训练必须显式构造：

```text
segment_start
segment_state
segment_length
complete_or_right_censored
scene_context_at_segment_start
```

要求：

- 只在阶段边界计算新意图的先验—后验一致性损失；
- 非边界时刻直接继承旧意图，不计算新状态分类损失；
- 持续时间只使用阶段开始时的场景和状态；
- 完整阶段使用完整持续时间似然；
- 最后未完成阶段使用右删失似然；
- 训练、验证、环境采样和确定性时长选择共用同一组持续时间函数；
- 交互意图直接控制未来一秒 `intent_plan`。

---

## 6. 核心修改四：多车联合计划约束

不增加逐车离散候选。联合性由以下结构实现：

```text
一个场景级持续意图
+
联合的一秒计划生成
+
每辆车受限的局部响应修正
```

使用现有动力学将完整一秒控制计划展开为预测状态，并增加：

```text
车辆重叠惩罚
负间距惩罚
动作边界
加加速度边界
跨车辆计划平滑约束
```

这些约束只保证多车计划的物理与关系一致性，不读取风险标签。

每次 0.2 秒更新的输入：

```text
history_states                 [B, 25, agents, 6]
history_valid                  [B, 25, agents]
graph_and_map_context
current_intent_state           [B]
remaining_intent_duration      [B]
previous_control_plan          [B, 25, background_agents, 2] 或 None
previous_relation_summary
START 时额外输入 B0 raw/std/valid
```

输出：

```text

applied_controls               [B, 5, background_agents, 2]
predicted_plan_states          [B, 25, background_agents, 6]

local_residual_plan            [B, 25, background_agents, 2]

intent_boundary                [B]

```

对外正式接口仍每 0.2 秒返回五帧实际执行状态；完整一秒计划作为审计输出。

## 8. 训练协议

训练必须按正式自回归过程展开：

```text
预测 25 帧计划
→ 执行前 5 帧
→ 用动力学得到背景车状态
→ 将生成状态写回历史
→ 输入该时刻已经发生的 logged ego 状态
→ 再预测 25 帧计划
```

损失仅保留：

```text
L_execute   前 5 帧执行状态与动作误差
L_plan      完整 25 帧计划状态与动作误差
L_overlap   相邻计划 20 帧重叠一致性
L_intent    仅边界时刻的新意图损失
L_duration  完整阶段或右删失持续时间损失
L_residual  局部响应修正幅值与平滑约束
L_joint     多车重叠、间距和物理边界约束
```

禁止重复监督同一控制量，禁止以真实完整动作直接监督局部修正量。

### 阶段 A：计划解码

- 冻结关系编码器和半马尔可夫状态模块；
- 训练一秒计划解码器和局部响应头；
- 新增输出层采用受控初始化，使初始执行前五帧尽量复现旧 BARS-M1 解码器。

### 阶段 B：持续意图

- 解冻状态先验、状态后验和持续时间模块；
- 使用显式阶段、边界意图损失和完整持续时间损失；
- 关系编码器继续冻结。

### 阶段 C：联合微调

- 仅在阶段 A、B 均通过一秒门槛后运行；
- 低学习率解冻关系编码器；
- 优化 1–5 秒自回归性能；
- 未通过门槛的 checkpoint 不得成为最佳模型。

## 11. 评测、对比与验收

只保留两个比较对象；它们必须冻结 checkpoint、配置、数据划分、Flow schema 与随机数
协议。规则模型、Flow 单独生成结果和过往候选均不再保留。

| 比较对象 | 角色 | 对后续 BARS 候选的要求 |
| --- | --- | --- |
| `catk_topk`（CAT-TopK） | 跨架构冻结对照 | 在同一 highD 序列、自车输入和世界随机数下报告配对 1 s/5 s 指标；其 START 使用冻结首秒摘要的事实必须单独披露。 |
| 当前 **BARS-M1** | BARS 系列唯一 incumbent | 是 `BARS-M2+` 的主晋升基线：1 s 不得劣化，5 s 必须改进，物理质量不得劣化。 |

当前 BARS-M1 不与自身比较；它的完整 highD checkpoint 与评测摘要被冻结，作为后续
尝试的固定起点。下述三项仅是机制消融，不构成新增基线。

必须报告：

```text
1 s、5 s ADE/FDE
1 s、5 s gap MAE
0.2 s 执行前缀误差
完整一秒计划误差
重叠计划不连续度
意图切换率和持续时间分布
局部响应修正幅值
车辆重叠率、负间距率和物理无效率
```

验收条件：

1. 相对当前 BARS-M1，1 秒 ADE、FDE 和 gap MAE 不得更高或者效果接近；
2. 相对当前 BARS-M1，5 秒自回归 FDE 不得更高或者效果接近；
3. 重叠计划不连续度低于无 `L_overlap` 消融模型；
4. 意图只在阶段边界切换，持续时间训练与采样定义一致；
5. 相对当前 BARS-M1，物理无效率和车辆重叠率不得更高；
6. 第一秒后 B0 不可观测；
7. BARS-M1 不依赖 CAT-K 代码或权重；
8. 完成与 CAT-TopK 的同序列 1 s/5 s 配对报告，并披露两者 START 信息条件差异；
9. 单元测试、三阶段训练和五秒闭环评测全部完成。

只保留三项消融：

```text
无重叠一致性
无持续交互意图，仅逐步状态
无局部响应，仅共享意图计划
```

不得继续增加新的模型组合。

## 12. 本轮 BARS-M2 实施状态

已实现一秒（25 帧）计划、五帧执行前缀、意图/局部残差分解、相邻计划重叠损失，以及
环境快照中的上一计划、关系摘要和持续状态。时间计划头只作用于未执行的 0.8 秒预测段，
以保持迁移的 M1 执行前缀稳定。

此前的 overlap-plan 和 prior-only 工件均已删除：它们的结论是长程收益不足以同时保持
tail 与所有主误差，因此不构成保留候选。

### 后续受限消融与停止决策（2026-07-16）

执行门控消融先以零门控复现 M1，再只允许极小的计划前缀混合；在相同 4,096 条验证
序列上，两轮 ROLL 的 5 秒 FDE 分别为 `0.75827 m` 与 `0.75854 m`，均劣于零门控
检查点的 `0.75769 m`，因此不进入联合微调。

为定位此前微弱长时域增益的来源，随后做了不训练的 prior 组件消融；它不是新基线，
也不是可推广模型，工件已删除。

完整 24,216 条 highD test 的该诊断候选虽将 5 秒 FDE 降至 `0.76590 m`，但 5 秒 ADE
升至 `0.19261 m`、交互 gap MAE 升至 `0.15763 m`；EVT-tail 5 秒 FDE 为 `0.82954 m`，
高于 M1 的 `0.82346 m`。严格同序列、同锚点、同随机数的 BARS-M1 配对（24,216 条，
2,000 bootstrap）进一步确认：

- 1--2 秒 ADE/FDE/gap 的 95% 上界均小于零；
- 3--4 秒至少一个主误差指标变差；
- 5 秒 FDE 为 `-0.002658 m`，但 ADE 为 `+0.001051 m`、gap MAE 为 `+0.001458 m`；
- EVT-tail（328 条）ADE/FDE/gap 的差异分别为 `+0.004513/+0.010044/+0.002711 m`，
  FDE 的 95% 上界为 `+0.021214 m`。

持续时间校准保持在 M1 的 `0.260198`，未发生额外漂移，但也未满足既有 `<= 0.10` 的
推广门槛。因此该路线明确 `not_promoted`：不启动 prior-only 再训练或联合阶段，不增加
新的基线，后续正式起点仍为冻结的 BARS-M1。该诊断工件已清理；其数值只保留在本节，
不再作为可运行候选。

### 当前唯一候选：BARS-M2 State-Supervised Clean-Plan Carry v5（2026-07-17）

prior-only 诊断和状态跟踪校正均已停止，不再作为候选。当前唯一 M2 不增加网络、状态或
基线：保留原有一秒计划头，只对其 25 Hz 物理展开状态施加监督；每次 0.2 秒重规划在第
3 秒后以 20% 有界混合执行上一轮无 B0 预测计划的下一 5 帧前缀。首 3 秒严格执行 M1
路径。配置、checkpoint 和正式报告均在 `behavior_anchored_semi_markov_m2_plan_state_v5/`。

- BARS-M1 配对（24,216 条、2,000 bootstrap）：1--3 秒三项主误差精确相等；4 秒、5 秒
  和 5 秒 EVT-tail 三项均严格改善。5 秒 FDE 差为 `-0.007494 m`（上界 `-0.007010 m`），
  tail FDE 差为 `-0.009357 m`（上界 `-0.004829 m`）；物理无效率和重叠率与 M1 相同。
- 计划状态监督后的独立 5 秒评测为 `ADE/FDE/gap = 0.191146/0.762671/0.155897 m`，tail
  为 `0.206159/0.815145/0.170052 m`；完整计划状态位置/速度 L1 为
  `0.122897/0.114103`。将 carry 提高到 30% 的单次验证校准虽改善全体指标，却使 EVT-tail
  三项回退，故工件已删除并固定为 20%。
- CAT-TopK 1 秒配对全部通过；EVT-tail FDE 差为 `-0.006812 m`（上界 `-0.005793 m`）。
  5 秒 FDE 差缩小至 `+0.076172 m`，tail 为 `+0.080825 m`；CAT 的冻结协议继续使用未来流
  动作摘要，结果必须与 BARS 的无未来输入条件分开解释。

### 已清理的联合计划诊断（2026-07-17）

在 v5 上以背景车成对相对状态/净距训练的两轮 `L_joint` 联合微调，验证集 5 秒 FDE 降至
`0.753008 m`；完整 BARS-M1 配对的 5 秒 FDE 差为 `-0.012395 m`，EVT-tail 为
`-0.011842 m`。相对 CAT-TopK 的完整 5 秒 FDE 差也由 `+0.076172 m` 缩小至
`+0.071270 m`。不过完整物理评测的无效率和重叠率均为 `0.000123885`，高于 v5 的
`0.000082590`（24,216 条中额外一例重叠），故不满足物理门槛，checkpoint、配置和训练
工件均已删除。

后续将 `L_joint` 扩展为 ego--背景计划标签及直接闭环车体净距，低权重与按原始接触面积
重新标定的高权重均未改变该重叠样本，且验证 FDE 分别仅为 `0.754177` 与 `0.754161 m`。
这说明该罕见错误不在该训练目标的可激活分布内；该净距损失代码及工件均已清理，不再重复
调权或增加同类损失。

同样以 4,096 条验证序列比较了各模型 hazard 的确定性众数持续时间选择。它使全体 5 秒
FDE 差降至 `-0.009492 m`，却使 EVT-tail FDE 差变为 `+0.002009 m`，故继续采用带固定
世界随机数的可重放持续时间采样；该临时评测开关和报告均已删除。

边界类别不平衡也做过一次严格的 Stage-B latent-only 校准：把正样本权重上限从 `20` 降为
`3`，冻结关系与计划解码器，只更新先验、后验及 hazard。训练损失下降，但验证集 ROLL 5 秒
FDE 从 `0.758460` 升至 `0.759620 m`，未通过起始 checkpoint 选择门槛，故专用配置、代码
和工件均已删除。

对 v5 已有的 20% clean-plan carry 还做了无训练的启动时刻校准：将启动从第 14 个响应步
提前至首秒后的第 5 步。在 4,096 条验证序列上，它从 2 秒起三项主误差均劣于 M1，5 秒
FDE 差为 `+0.054526 m`，EVT-tail FDE 差为 `+0.146980 m`。这表明早期重用旧计划会累积
错误；临时配对报告已删除，v5 保持第 14 步启动。

`L_joint=0.05` 从 v5 继续的一轮全量训练也未形成可替代的较短训练时长：验证 ROLL FDE
为 `0.75917 m`，高于 v5 的 `0.758460 m`。结合两轮版本虽改善误差但新增物理重叠的结论，
该联合损失不再做时长扫描；一轮配置和输出均已删除。

v5 本身的第 4 个计划头训练 epoch 也被严格否决：前三轮验证 FDE 曾连续下降至
`0.758460 m`，但从该 checkpoint 继续一轮后回升至 `0.75916 m`。因此保留 epoch 3 的
v5 checkpoint，不再延长同一训练阶段；临时配置和输出均已删除。

最后对固定 carry 做过一次只读一致性诊断：计划不一致度与验证 EVT-tail 的相对 FDE 回退
有弱正相关，但按相邻旧/新计划一致性衰减 carry（尺度 `0.005/0.01/0.02`）会同时抹去
全体收益，tail 仍未转为改善；最保守尺度的全体 5 秒 FDE 仅为 `-0.000321 m`，tail 为
`+0.000417 m`。因此不保留该门控代码或配置，继续使用固定 20% carry。

carry 对齐状态监督也只运行了首个完整 epoch：仅将既有状态计划损失在下一响应会复用的
第 6--10 帧加倍，未增加任何模型输入或头；但验证 ROLL FDE 为 `0.76455 m`，劣于 v5
第 1 epoch 的 `0.760221 m`。训练在首轮后终止，配置、输出和这项权重代码均已删除。

对 hazard 作更粘滞的全局无训练校准（logit `-0.5`）也未超过 v5：全量 BARS 配对 5 秒
FDE 差仅为 `-0.007508 m`（v5 为 `-0.007494 m`），tail 为 `-0.009316 m`（v5 为
`-0.009357 m`），且 2 秒门槛不再精确等价。它不改善与 CAT 的结构性差距，故未加入配置。

最后把采样到的剩余持续时间接入 M2 的未执行时间计划头，以满足正式接口中的
`remaining_intent_duration`；M1 执行头、输入和状态数均未改变。但该输入在训练使用的
posterior 阶段与 ROLL 先验采样之间产生分布失配，首个完整 epoch 的验证 FDE 为
`0.76411 m`，劣于 v5 的 `0.760221 m`。训练在首轮后终止，配置、输出和代码均已删除。

现有的 late closed-loop endpoint loss 也做过一次唯一的温和激活（`late_roll_weight=0.25`）：
它不引入模型结构或输入，但首个完整 epoch 的验证 FDE 为 `0.76444 m`，同样低于 v5 的
`0.760221 m`。这说明简单提高末端误差权重会破坏整段闭环一致性；训练在首轮后停止，配置
和输出均已删除。

最后验证了一次不访问未来自车轨迹的局部 TTC 制动/加速响应（从每个 0.2 秒响应起点的自车
常速度外推）。4,096 条验证序列中，v5 的物理无效率、负间距率与重叠率本来均为零；`0.8 s`
时域的响应仍为零，未修复任何样本，且 EVT-tail 相对 M1 的 FDE 变为 `+0.002374 m`（上界
`+0.015864 m`）。因此该响应层、参数开关、测试和临时配对报告均已删除；不将罕见且与目标
轨迹本身一致的贴近通过误判为可由局部反应规则解决的问题。

最后还校正过一次 M2 prior 闭环训练与部署 carry 的一致性：让训练中的先验路径也在第 3 秒后
执行上一轮无 B0 计划的 20% 前缀混合。它不增加输入、状态、头或损失，但从 v5 续训一轮后的
完整验证 ROLL FDE 为 `0.759039 m`，高于 v5 的 `0.758460 m`。因此该实现、v6 配置和输出均
已删除，不进入测试集；当前仍以 v5 的原有训练路径为唯一候选。

对同序列 CAT-TopK 与 v5 的只读误差归因显示，差距主要位于背景车横向变化和速度变化的轨迹，
而非近距交互本身。因而仅把既有 local temporal residual 的 L1 收缩从 `0.01` 降至 `0.002`，
不新增输入、状态或头；但从 v5 续训一轮后完整验证 ROLL FDE 为 `0.759157 m`，仍高于
`0.758460 m`。该配置和输出均已删除，不进入测试集，也不继续扫描同一权重。

对 clean-plan carry 启动点做的唯一中点校准（第 10 个响应步，介于已拒绝的第 5 步和 v5
固定的第 14 步之间）也未通过：4,096 条验证序列的全体 5 秒 FDE 相对 M1 为 `-0.006062 m`，
但 EVT-tail FDE 为 `+0.026389 m`（95% 上界 `+0.062026 m`）。因此不再扫描启动时刻；v5
继续固定在第 14 步，临时报告已删除。

为避免稳定直行片段掩盖横向/速度变化的计划误差，还曾将既有计划状态损失按未来控制变化
幅度加权（不引入新输入或解码头）。从 v5 续训一轮后完整验证 ROLL FDE 为 `0.759028 m`，
高于 `0.758460 m`；因此不继续扫描动态权重，相关代码、测试、配置和输出均已删除。

最后尝试让第 3 秒后的 M2 时序计划直接修正每次重规划的执行前 5 帧（v8）：为避免未训练的
前缀嵌入，初始化时复制同一计划第 6--10 帧的嵌入；首 3 秒及 M1 路径仍严格不变。虽首轮
验证 ROLL FDE 轻微降至 `0.758354 m`，完整测试的 5 秒 FDE 却为 `0.764502 m`（v5 为
`0.762671 m`），EVT-tail 为 `0.817508 m`（v5 为 `0.815145 m`）。BARS-M1 全量配对的
1--3 秒仍精确相等，5 秒 FDE 差为 `-0.004637 m`（上界 `-0.003486 m`），但 EVT-tail 的
ADE/FDE/gap 三项上界为 `+0.000129/+0.003653/+0.000514 m`，均未通过零容忍门槛；物理
无效率和重叠率保持 `0.000082590`（2/24,216）。故直接执行开关、初始化逻辑、测试、v8
配置和训练/评测工件均已删除，不运行无资格候选的 CAT 对比，也不再重复这一执行前缀改动。

为检验 v5 的 clean-plan carry 是否应随已生成状态对上一计划的跟踪误差自适应衰减，读取了
不含标签的边界误差 `|Δposition| + 0.2|Δvelocity|`：4,096 条验证序列中常规/EVT-tail 均值仅
为 `0.001618/0.001705 m`。按唯一、分布确定的 `5 mm` 尺度衰减 carry 后，tail FDE 降
`0.001507 m`，但全体 5 秒 FDE 上升 `0.001779 m`，扩大而非缩小 CAT 差距；因此不扫描尺度。
该状态跟踪 gate、诊断脚本、临时配对报告和测试均已删除。

随后只试验一次先验计划监督：保持 v5 的计划头、carry 与 M1 执行前缀，额外对先验 ROLL
路径的未执行 0.8 秒计划施加 `0.05` 权重的真实计划损失，以消除 posterior-plan 与部署 prior
的条件差。该损失确实激活（训练/验证为 `0.136983/0.140699`），但从 v5 续训一轮的完整验证
ROLL FDE 升至 `0.759206 m`，高于 `0.758460 m`，首秒门槛虽仍通过也无资格进入测试集。先验
计划损失、v9 配置、checkpoint 和所有输出均已删除，不继续扫描该权重。

计划诊断显示 v5 未执行一秒计划的状态误差会随帧位增长：4,096 条验证序列上首帧的位置/速度
L1 约为 `0.232/0.213`，第 25 帧为 `0.353/0.304`。因此在不改变任何执行前缀的前提下，只对
计划第 25 帧额外施加 `0.10` 状态监督（v10，区别于已拒绝的五秒闭环 endpoint loss）。该损失
训练/验证值为 `0.498572/0.494885`，但完整验证 ROLL FDE 升至 `0.759221 m`，仍高于 v5 的
`0.758460 m`。说明在既有时间计划头上加局部末端权重同样不能改善闭环；相关损失、配置、
checkpoint 和输出均已删除，不再继续叠加任何同类计划损失。

最后检查了计划结构本身：全局 `intent_time` 接收半马尔可夫状态，逐车 `local_time` 却未接收
该共享意图。v11 因此仅向 local temporal residual 新增零初始化的意图输入列；迁移后初始 5 秒

无效率和重叠率相同。故不进行 bootstrap/CAT，对应连接、迁移逻辑、测试、v11 配置和工件均已
删除；不再通过扩大 local temporal residual 继续搜索。

最后补齐了一次原规范中的“时间展开后逐车联合交互”（v12）：在既有 local temporal residual

迁移白名单、测试、配置和训练工件均已删除；当前不再保留未获验证支持的额外计划层交互。

随后仅向未执行计划加入由当前自车/背景状态和速度确定的时间展开相对运动（v13），不读取

`0.206159/0.815145/0.170052`）。虽 FDE 有 `0.000042 m` 的微小变化，tail 与其余主误差均
回退，物理率相同；不进行成对/CAT 对比，代码、配置、测试和工件均已删除。

在关系编码侧最后试验一次零初始化的第二消息传递（v14）：它只面向 `35 m` 内的有效车辆对，
