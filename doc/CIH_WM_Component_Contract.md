# CIH-WM 方法合同

CIH-WM 是一个两层交通世界模型：一个冻结的事实转移层负责重建已经发生的交通演化；一个因果响应层负责在 ego 动作改变时生成受影响车辆的行为调整。

```text
冻结扩散计划条件事实转移层 ─→ 基础背景车动作
                                      │
已实现状态 ─→ 直接后车影响路由 ────────┼→ 机制引导的人类响应校准 ─→ 受约束动作 ─→ 下一状态
```

## 算法模块

1. **冻结事实转移**：一个扩散计划条件的交通状态转移模型。它对所有规范背景车槽位（包括 `same_rear`）执行事实重建，是 CIH-WM 的固定基础，不是本文新增的因果方法。
2. **直接后车影响路由**：从已实现状态构建 ego 到直接受影响后车的响应权限。它不读取记录未来、待执行 ego 动作或干预标签；二跳传播当前关闭，且不属于验收范围。
3. **机制引导的人类响应校准**：校准纵向跟驰机制给出方向性先验，冻结人类响应先验给出自然分布，学习校准器在权限内修正动作幅度；加速度和 jerk 约束保证修正可执行。

## 实现与训练边界

关系编码、置信过滤、协同 jerk 解码和 25 Hz 积分都属于冻结事实转移的实现细节。PPO、监督损失、三档制动对比、highD 事件集与人类支持集都是训练或评测机制，而不是运行时算法模块。横向因果响应和二跳传播当前均关闭。历史 `same_rear` 掩码评测不能与当前全背景车协议的结果混用。

`Diffusion-Guided HiQR` 只是冻结事实检查点的历史名称和兼容别名，不是 CIH-WM 的组件名。
