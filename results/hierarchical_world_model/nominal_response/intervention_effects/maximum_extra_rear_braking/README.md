# Maximum extra rear-braking diagnostic

This playback is selected from all 205 eligible test interventions by the
most negative candidate-minus-common mean acceleration of the affected
same-rear vehicle during the fixed ego-braking window. It is a maximum-effect
diagnostic, not a representative event and not evidence of safety improvement.

For this event, the current controller adds 0.2089 m/s² of rear braking
relative to frozen common physics. The collision outcome remains unchanged.
See the parent `all_test_intervention_effects.csv` and JSON report for the
complete distribution and selection rule.
