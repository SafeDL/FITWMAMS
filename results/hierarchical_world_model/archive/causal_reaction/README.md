# Archived causal-reaction experiments

This directory contains earlier calibrated-residual, PPO, GAIL, rule-based and
diagnostic runs. None is the selected nominal-response candidate, and none is
loaded by the active configuration or scripts.

The shared event evidence formerly stored inside an early PPO run now lives at
`results/hierarchical_world_model/reaction_events/`. Historical manifests may
retain their original paths; they are provenance records, not runnable active
commands.
