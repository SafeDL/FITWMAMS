# 创新结构、前案边界与针对性查新分析

2026年10月25日。对应《一种面向多失效域的自动驾驶交互测试与修复方法》整体框架深化稿。保留已认可的完整方法范围，补充最接近技术核对，并把代码中已有的输入、执行及反馈关系进一步写入正文和候选保护范围；此前文本均保留。

## 1 整体发明定位与本次调整

项目具有一条完整的方法主线：自然长尾事件挖掘与风险尾部标定，为场景生成确定数据来源；条件Flow与扩散残差提供具有层次的交通变化；参考适用性和背景驾驶响应将变化落实为交互；分支搜索发现分散的失效；实际纠正和成功保持使这些发现进入ADS修复；新版本复测再更新测试重点。本次保留这条主线，并进一步明确生成变量如何成为搜索对象、何种实际执行改变周车预测，以及新旧策略比较如何落实为后续调用。

整体技术问题确定为：在有自然风险来源的交互世界中，如何持续取得不同区域的真实缺陷，并让修正后的结果能够可靠地反馈到下一轮测试。核心载体为分层世界的完整输入及实际执行版本；每一层的输出都在后续操作中继续使用，而不是将EVT、Flow、扩散、搜索和训练并列为模型清单。

| 方法层次 | 项目中有实质内容的技术关系 | 在整体方案中的作用 |
| --- | --- | --- |
| 长尾事件与EVT | 多车尺寸及相对运动形成安全包络风险，峰值与暴露合并；自然尾部确定生成来源，实际安全失效确定搜索终层 | 分开处理“自然风险稀有”与“当前ADS确实失效” |
| 场景条件Flow | 占位、初态与稀疏结点条件分解，尺寸经验采样与物理投影独立处理 | 产生可解码、可恢复且能分组控制的交通条件 |
| 分层扩散世界 | 结点控制长期意图，PCHIP与条件残差构成局部运动；世界生成扩散与主车规划扩散分别处理 | 将长期交通变化与局部运动变化落实为不同操作对象 |
| 交互执行 | 完整经验误差轨迹参与计划适用性；一次交接承接已开始机动；分别记录控制权和实际执行响应，后者决定周车预测来源 | 在保留生成意图的同时，让已发生的控制后果进入后续交互判断 |
| 多失效域发现 | 在生成与响应基础变量上提议，组概率按已执行风险差更新并逐层冻结，分支独立推进 | 将模型层次变为搜索空间，减少全局精英筛选对局部分支的挤压 |
| 分散档案及邻点 | 分支容量、祖先上限、最远点代表与真实单组相反端点；训练取材按分支轮转、失效祖先去重 | 控制重复来源，使发现记录具有修复及回归检查用途 |
| 原生修复 | 同输入纠正及同次联合标签；成功来源保持对应功能；监督与当前策略强化学习分别适配 | 避免把不同含义的执行记录一律当成同一种标签 |
| 接纳与反馈 | 世界参数固定；同输入重测旧失效与旧成功；当前策略重新建树并映射端点；公平分配及新先验探索 | 保持比较条件清楚，并使修复与回归改变后续实际调用 |

前两组关系回答“怎样取得具有明确生成来源的实际交互失效”，后两组回答“怎样使这些失效成为修复材料并继续指导当前模型测试”。两类反馈有不同的保持条件：组敏感度保持策略而改变世界输入；版本反馈保持世界输入而改变策略。因此，它们分别控制选组与选分支，具有确定的计算对象和执行后果。

## 2 与已提交前案的实质边界

已提供的前案《一种面向安全关键事件的自动驾驶长尾测试方法》的实际独立主题为“自动驾驶长尾测试分布构建方法、电子设备和程序产品”。其权利要求1已覆盖自然尾部事件、条件联合分布、条件动作生成及长尾测试分布；权利要求2、4进一步包括EVT；权利要求5至7涉及闭环风险、子集模拟及风险量化。前案说明书还明确列出归一化流类联合模型及条件扩散，并已描述固定条件的潜变量扰动。

因此，“增加Flow名称”“将扩散称为世界模型”“再次排列EVT与子集模拟”不能形成充分的前案区别。本次正文完整说明这些基础，是为了交代新方案如何实施；主项必须继续限定交互执行、生成变量分组搜索、来源档案、原生修复及新策略复测的进一步关系。

| 比较对象 | 前案已提供内容 | 当前方案进一步具体化的内容 |
| --- | --- | --- |
| 交通对象 | 跟驰、切入条件向量及目标车动作，允许其他场景扩展 | 多背景槽位、初态、稀疏意图与联合残差分别解码，并继续暴露驾驶、机动及响应变量 |
| 交互执行 | 生成动作进入仿真，得到主车与目标车闭环轨迹 | 按参考适用性从当前真实状态转入响应，承接机动与时标；实际响应标志控制预测来源；相同外生输入下允许不同ADS产生不同周车轨迹 |
| 搜索目标与组织 | 以EVT阈值及子集模拟估计条件风险 | 真实失效作为终层；按世界变量组进行逐层固定的提议，分支各自推进并形成来源分散档案 |
