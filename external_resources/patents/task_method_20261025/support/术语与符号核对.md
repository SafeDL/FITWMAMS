# 术语与符号核对

对应任务方法论修订稿。主文档中的数学结构均生成原生Office公式；本表为编辑核对记录。

| 记号或术语 | 唯一用途及定义位置 |
| --- | --- |
| ADS、主车、背景车 | 被测驾驶系统、由其控制的车辆、测试环境车辆；第1节 |
| r_t、R(τ) | 瞬时风险、峰值加暴露的事件风险；式（1） |
| Δt、λ_R | 物理采样间隔、暴露项的预定权重；式（1） |
| u、p_u、κ、σ_E、ε | EVT阈值、超阈比例、形状、尺度、对数正下界；式（2） |
| F̄_R、S_E | 自然风险生存函数及其对数风险尺度；式（2） |
| M、C_0、K、D | 背景占位、初态、稀疏位置结点、车辆尺寸；第4.1节 |
| q_tail | 条件建模层的尾部采样分布；式（3）；物理投影后的测试由完整映射确定 |
| P、I算子、R_Θ算子、z_P | 背景软参考、插值算子、条件残差生成器、世界扩散噪声；式（4） |
| Θ | 本轮固定的世界生成及执行参数，区别于ADS参数；式（4） |
| q_ij、N_E、T_t、d_ij | 车辆对预测冲突支持度、完整实现数量、预测时域、矩形分离量；式（5）；不解释为事故概率 |
| i、j、ℓ、t、s | 车辆索引、成组实现索引、当前物理时标及预测物理时标；式（5） |
| b_i、A_i | 接管状态、接管条件标志；式（6）；与分支索引b区分 |
| 控制权标志、实际响应标志 | 前者决定由谁控制，后者经实际动作与限幅参考动作比较置位，决定其他车辆预测的来源；第4.2节 |
| μ | 八组基础输入的联合先验；式（7）后的定义；与条件生成密度q_tail区分 |
| 𝓕_π、μ_π,b、ℬ_b、c_b、Z_π,b | 策略失效集合、分支条件分布、输入区域、层阈值及正归一化常数；式（8）后及式（9） |
| 𝓚_b,g、𝓚_bᴶ、𝓚_b、γ | 固定作用坐标的单组核、不同组联合核、混合核及正联合比例；式（13）；与稀疏结点K区分 |
| 𝓚_bᴬ | 区域及阈值门控形成的接受—拒绝转移核；式（14）后；不变性限定于固定配置及正质量条件集合 |
| π_n、𝓔_bᶠ、𝓔_bˢ | 接纳的新策略、当前分支内实际重测的旧失效／旧成功集合；式（15）；f、s为来源标签 |
| ω、G_Θ、I、S_Θ | 世界基础变量、实例化映射、完整实例、闭环执行映射；式（7） |
| π、τ_π | 当前被测策略及其实际联合执行；式（7）；实际轨迹不同于背景软参考P |
| F_π、H_π | 实际安全失效指示、条件层分数；式（8）；与自然风险生存函数F̄_R区分 |
| g、z_g、z_g'、ρ、ε_g、I_g | 变量组、当前及提议值、pCN尺度、标准高斯创新及单位协方差；式（10） |
| b、s_b,g、ν、τ_π′ | 分支索引、组敏感度、平滑系数、同策略提议输入下的轨迹；式（9）、（11）；敏感度不作因果贡献 |
| p_b,g、δ、𝒢_b、h | 单组选择概率、正基础权重、当前层可用组集合及求和组索引；式（12） |
| a_b、ω' | 接受指示、提议完整基础变量；式（14）；a_b不是接受概率密度 |
| w_b、u_b、v_b、n_b | 分支权重、持续失效比例、成功回归比例、已分配提议执行数；第4.4节及式（16） |
| 成功邻点 | 档案中相对于安全判据的非失效邻点；第4.4节；进入保持材料还须完整及未停车 |
| L_C、L_N、L_0、L_S | 纠正监督、原任务监督、最初模型保持、近期成功模型保持；式（17） |
| λ_N、λ_0、λ_S | 抽样比例及损失系数共同确定的组合权重；式（17） |
| Y、V、Ȳ | 主车规划器的联合未来表示、真实未来掩码、掩码处理后的干净内容；式（18）；V与场景占位M区分 |
| Z_η、η、α、σ、ξ | 训练带噪输入、扩散时刻、原生加噪系数及训练高斯噪声；式（18）；ξ与世界噪声z_P区分 |
| F_θ、o、θ、θ_r | ADS学生去噪器、因果观测、学生参数、成功部署参照参数；式（19）、（20）；与世界参数Θ区分 |
| D_C、D_S、掩码平方范数 | 纠正材料、成功保持材料、有效未来的均方误差；式（19）、（20） |
| 多失效域、经验搜索分支 | 面向分散失效区域的搜索目标及当前有限证据的组织单位；第4.3节；不据分支数证明严格连通域数 |

章节4的六个小节按输入、生成执行、搜索、档案反馈、修复及接纳展开。公式共20项；N_E用于预测误差实现数量，L用于监督组合目标，避免混用。背景扩散与主车扩散规划器分别定义；风险标定与实际失效分别定义；安全端点与保持训练资格分别定义；旧端点与当前条件粒子分别定义。
