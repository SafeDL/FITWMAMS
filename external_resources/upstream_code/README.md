# 外部参考代码

本目录保存 TrafficBots、VBD、ad-rss-lib、CATK 和 nflows 的上游源码快照。Flow 模块会从 `nflows-master/` 加载本地 nflows；其他快照主要用于方法核对，不能直接视为本项目已训练或部署的模型。本项目的世界模型和外部基线入口分别见 [`hierarchical_world_model/`](../../hierarchical_world_model/README.md) 与 [`external_model_baselines/`](../../external_model_baselines/README.md)。各外部项目的许可和使用说明以其自身 README、LICENSE 为准。
